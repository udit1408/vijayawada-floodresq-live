# Vijayawada FloodReSQ Live DSS

Canonical public shell for the Vijayawada FloodReSQ live decision-support system.

Current verified stakeholder URL:

https://vijayawada.airesqclimsols.com/

The GitHub Pages URL for this repository is a static fallback only. Do not share it as the working DSS link until a Pages build is verified to serve the latest `index.html`.
