# Vijayawada FloodReSQ Live DSS

Canonical public shell for the Vijayawada FloodReSQ live decision-support system.

Public URL: https://udit1408.github.io/vijayawada-floodresq-live/

This static shell connects to the FloodAstra backend configured in `assets/config.js` for chat, live-data checks and GPU-backed nowcast runs.
